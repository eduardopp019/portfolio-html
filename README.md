Meu portfólio pessoal, desenvolvido para apresentar um pouco sobre mim, meus conhecimentos, projetos e experiências na área de tecnologia.

## Sobre o projeto

Este site reúne informações sobre minha trajetória na área de TI e alguns dos projetos que desenvolvi durante meus estudos e experiências.

O objetivo é ter um espaço para apresentar meu trabalho, compartilhar projetos e facilitar o contato com empresas, recrutadores e pessoas interessadas nos meus serviços.
